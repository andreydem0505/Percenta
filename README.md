# Aubenia

Кэшбек всех ваших карт — на одном экране. Найдите категорию, сравните проценты и выберите банк для покупки.

[Открыть Aubenia](https://cashback-44e5c.web.app)

**Без регистрации. Скриншоты остаются на вашем устройстве.**

На скриншотах — демонстрационные данные.

## Возможности

- **Из скриншота в категории.** Локальное распознавание PNG, JPEG, WebP и HEIC с проверкой результата.
- **Все предложения под рукой.** Ни один банк не скрывается. Поиск и выделение кэшбека на любые покупки.
- **Полный контроль.** Ручное добавление, редактирование и удаление категорий.
- **Перенос между устройствами.** Экспорт и импорт JSON с предпросмотром.
- **Спокойный интерфейс.** Графитовая палитра, мягкие цветные иконки категорий и быстрые переходы в приложения банков на телефоне.

Результат распознавания можно исправить перед сохранением. Записи хранятся в браузере: перед очисткой его данных сохраните JSON-копию.

## Запуск

Node.js 22.18+.

```sh
npm ci
npm run dev
```

`npm test` — тесты. `npm run build` — готовая сборка в `dist/`. `npm run preview` — просмотр сборки.

React · TypeScript · Vite · Tesseract.js
